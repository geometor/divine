geometor.divine.catalog.schema¶

Data schemas and exact symbolic certification for the Golden Ratio Catalog.

Every cataloged construction in geometor.divine.catalog returns an exact symbolic Model together with a verified GoldenCertificate recording exact SymPy lengths, Rational Trigonometry quadrances, Lemoine Géométrographie step metrics, algebraic number field membership, and all golden sections and chains discovered automatically by geometor.divine.golden.
