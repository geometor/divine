geometor.divine.golden¶

Find and analyze exact symbolic golden sections in GEOMETOR models.

This module provides fast numerical pre-filtering paired with 100% exact Rational Trigonometry symbolic verification (geometor.model.quadrance() and geometor.model.zero_test()) to detect golden sections and chains across lines and collinear point configurations in geometor.model.Model.

Identify maximal chains of connected golden sections.

geometor.divine.golden.is_section_golden(section_points: collections.abc.Sequence[sympy.geometry.Point2D]) → bool¶

Check whether three ordered collinear points form an exact golden section.

First screens segment quadrances numerically, then proves exact equality Q_long - (phi + 1) * Q_short == 0 symbolically via quadrance() and zero_test().

Parameters:

section_points – Sequence of three ordered collinear points (P, Q, R).

Returns:

True if max(|PQ|, |QR|) / min(|PQ|, |QR|) == phi exactly.

Return type:

bool
